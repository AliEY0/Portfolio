Gameontwikkeling

Platformer Game

Een 2D platformspel waarin de focus lag op gestructureerde gamecode, duidelijke design patterns en het toepassen van SOLID-principes binnen een interactieve gameplay-omgeving.

Doel van het project

Het project was een oefening in het bouwen van een game die technisch duidelijk georganiseerd blijft. Beweging, interactie, levels en gameobjecten moesten logisch samenwerken, zonder dat de code onnodig complex werd of moeilijk uitbreidbaar aanvoelde.

Wat ik leerde

Door met gamecode te werken werd het belang van duidelijke verantwoordelijkheden extra zichtbaar. Kleine beslissingen in de structuur hebben snel invloed op hoe makkelijk nieuwe gameplay-elementen toegevoegd kunnen worden en hoe overzichtelijk het project blijft.
