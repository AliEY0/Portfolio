C / C++

Terminal projecten

Een verzameling kleine projecten zoals een UNIX shell, een terminal file browser, een QR-code generator en andere C/C++ oefeningen die mij helpen om dichter bij de basis van software te werken.

Focus

Deze projecten helpen mij om dichter bij de basis van programmeren te werken, zoals geheugen, bestanden, processen, input/output en algoritmisch denken.

Waarom dit nuttig is

Door kleinere tools te bouwen leer ik sneller experimenteren en zie ik sneller wat wel of niet werkt. Elk project heeft een duidelijk doel en dwingt mij om technische problemen compact en begrijpelijk op te lossen.
