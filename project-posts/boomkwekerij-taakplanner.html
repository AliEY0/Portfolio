.NET 10 / Blazor

BTP - Boomkwekerij Taakplanner

Een full-stack taakbeheerplatform voor een boomkwekerij, gebouwd met ASP.NET Core, Blazor, EF Core, SQL Server, Docker en GitLab CI/CD om planning en opvolging overzichtelijker te maken.

Doel van het project

Dit project draait rond het plannen, opvolgen en beheren van taken binnen een boomkwekerij. De applicatie helpt gebruikers om werk overzichtelijk te verdelen, verantwoordelijkheden duidelijker te maken en de status van taken centraal bij te houden.

Technische aanpak

De backend bestaat uit ASP.NET Core API's met Entity Framework Core en SQL Server. De interface werd opgebouwd met Blazor, zodat de applicatie praktisch blijft voor gebruikers en tegelijk technisch onderhoudbaar blijft voor verdere ontwikkeling. Docker en CI/CD zorgen ervoor dat de applicatie reproduceerbaar kan worden gebouwd, getest en uitgerold.
