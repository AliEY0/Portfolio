Bekijk het originele probleem op Project Euler

Probleemstelling kort

In dit probleem krijg je duizend pokerhanden voor twee spelers. Per regel staan eerst de vijf kaarten van speler 1 en daarna de vijf kaarten van speler 2.

Je moet bepalen hoeveel handen speler 1 wint volgens de normale volgorde van pokerhanden.

Algoritme

Dit is het probleem dat ik heb opgelost: https://projecteuler.net/problem=54.

Dit is meer een implementatie type probleem dan een wiskundig probleem.

Ik raad je eerst aan om het zelf te proberen vooraleer je de oplossing raadpleegt.

De code is als volgt:

Player 1 heeft 376 keren gewonnen
Player 2 heeft 624 keren gewonnen
Uitvoeringstijd: 0.008321 seconden
